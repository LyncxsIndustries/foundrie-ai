# Foundrie AI Skills Workflow

## Overview
This document outlines the mandatory UI/UX workflow for Foundrie AI and all projects generated by Foundrie AI. Foundrie has adopted a premium visual aesthetic driven by the "Foundrie AI Skills" framework. This ensures that every component, layout, and interaction meets Awwwards-winning standards, utilizing high-end design patterns like glassmorphism, dynamic micro-animations (GSAP), tailored HSL colors, and premium typography.

## Mandatory Agent Workflow
Any AI agent working on, extending, or modifying Foundrie AI (or building a project generated by Foundrie) **MUST** adhere to the following strict guidelines:

1. **Research & Context Integration**
   - **MUST Read Research Files:** Agents must read all files in `research/` to understand the foundational product rules and historical implementation context.
   - **MUST Use Foundrie AI Skills:** Agents must actively use the UI generation skills located in `.agents/skills/` or `project-kit/skills/` (e.g., `imagegen-frontend`, `high-end-visual-design`, `minimalist-ui`, etc.) whenever touching the frontend.

2. **Examples as the Source of Truth**
   - **MUST Use the `examples` Folder:** The `project-kit/examples/` folder contains reference implementations. Agents must study and clone these patterns to ensure that new UI elements perfectly match the established aesthetic.
   - Do not invent ad-hoc styles. If a pattern exists in `examples/`, use it exactly.

3. **Inspiration (Inspo) Utilization**
   - **MUST Use the `inspo` Folder:** The `inspo/` folder contains visual screenshots and references of the expected final result. Agents equipped with vision models must analyze these images before generating or modifying UI code to guarantee that the contrast, spacing, typography, and layout match the premium visual target.

4. **Projects Generated by Foundrie**
   - The Foundrie ZIP builder (`lib/zip/build-project-zip.ts`) is hardcoded to automatically bundle the local `project-kit/skills`, `project-kit/examples`, `inspo`, and `research` folders into every generated project.
   - This ensures that downstream agents (like RUWA) have the exact same Foundrie AI Skills context and enforce the same premium UI standards on generated products.

## Enforcement
These rules are enforced via **Hard Rule 26** in `AGENTS.md`. Deviation from the Foundrie AI Skills design system (e.g., using default generic Tailwind colors, omitting hover micro-interactions, ignoring the `inspo` references) is considered a violation of the project contract.
