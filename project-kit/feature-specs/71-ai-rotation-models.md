# Feature Spec: AI Rotation Models Enhancement

## 1. Overview
Integrate Gemini 3.6 Flash and 3.5 Flash-Lite models into the AI Rotation engine. Improve conversational flow to ensure the AI knows when to stop, making it feel more like a structured conversation with Foundrie AI.

## 2. Requirements
- Update model configurations to support Gemini 3.6 Flash / 3.5 Flash-Lite.
- Implement conversational limits based on task complexity (simpler tasks end sooner).
- Ensure AI uses RAG memory properly to sync context without asking redundant questions.
