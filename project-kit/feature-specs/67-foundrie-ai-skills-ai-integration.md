# Feature Spec: Foundrie AI Skills AI Integration

## 1. Overview
Bake the newly installed Foundrie AI Skills into Foundrie AI. Agents must be aware of and utilize these UI skills (e.g., image-to-code, imagegen-frontend, UI design) when building features and generating code.

## 2. Requirements
- Ensure Foundrie AI Skills context files are read by the AI Rotation Engine.
- Use these skills when analyzing screenshots and generating UI code.
- Apply high-end visual design patterns automatically during UI generation.
