# Feature Spec: Global Theme and Contrast Fix

## 1. Overview
Revamp the global theme, colors, and contrast using Taste Skills guidelines. The entire app experience must look premium with deep, harmonious color palettes, fixing issues like flaky project card opacity and poor contrast.

## 2. Requirements
- Implement Taste Skills premium color palettes (HSL tailored colors, sleek dark modes).
- Fix project cards opacity issues to ensure high visibility and contrast.
- Update global CSS to adopt vibrant colors, glassmorphism, and curated typography.
